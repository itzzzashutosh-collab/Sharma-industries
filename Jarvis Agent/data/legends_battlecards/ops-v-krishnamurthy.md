## 🛠 CONCRETE EXECUTION STEPS

**1. Fill Station — Semi-Auto to Fully Auto**
- Procure 25kg servo-controlled filling valve (₹85,000 per unit, from Jalandhar vendor). One valve fills in 12 seconds. Two valves = 300 bags/hour.
- Add load-cell checkweigher (₹42,000) on belt post-fill to auto-reject under/over-weight bags. This eliminates giveaway and customer complaints at destination markets.

**2. Conveyor Integration (Ford Principle)**
- Install 15-meter roller conveyor spanning: Bulk Material Hopper → Filling → Capping → Bag Sealing → Pallet Stacking.
- Key: Every station must hand off without manual transfer. The bag moves automatically. Operator only does one task — cap the bag or stack on pallet. No walking, no carrying. This cuts cycle time by 40%.

**3. Raw Material Inflow — Buffer Tank Strategy**
- Maintain 2-day raw material buffer (Quartz sand, binding agent, water). Automate powder dispensing via screw conveyor into batching tank. One operator manages two tanks simultaneously.
- Scheduled delivery slots: Sand arrives Mon/Wed/Fri. Binding agent arrives Tue/Thu. Water stored in 10,000L overhead tank.

**4. Packing & Pallet Flow**
- Palletize in 20-bag layers, 4 layers per pallet = 80 bags/pallet. Forklift loads directly from conveyor end to outbound area. No manual stacking.
- Each pallet wrapped with stretch film (₹18 per roll, 500 rolls/month at Phase 3 volume).

**5. Quality Gate — Pre-Dispatch Check**
- At conveyor exit: 1 random bag per 50 bags tested for viscosity and texture consistency. Record in logbook. Any deviation = entire batch held for re-mix.
- Zero defect target = zero returns to Bundi = higher dealer trust.
