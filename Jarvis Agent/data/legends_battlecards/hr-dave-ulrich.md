### 2. Execution Steps — Zero to Pan-India

**Step 1: Zone-Level Payroll Pods (Bundi → North → Central → South)**
Create 4 regional payroll pods. Each pod has one HR Coordinator + one Finance Reconciler. Bundi HQ owns the master ledger; zone pods own local disbursement. This cuts per-rep processing time from 48 hours to 8 hours.

**Step 2: Bag-Count Auto-Capture via Dealer Acknowledgement**
Every 25kg Rustic bag dispatched generates a unique QR-linked serial. Dealer acknowledges receipt on WhatsApp / portal within 24 hours. This auto-populates the rep's dispatch incentive column — no manual entry, zero audit lag.

**Step 3: The Charan Loop — Pay-for-Outcome, Not Pay-for-Activity**
Ram's principle: *Compensation must flow where cash converts.* Incentive released only after dealer payment confirmation (7-day credit cycle). If dealer hasn't paid by Day 8, the corresponding bag incentive enters "hold" — released on Day 9 or deducted if return logged. This aligns rep effort with actual cash-in, not just physical dispatch.

**Step 4: Quality Gate — The 3% Return Rule**
If a rep's total dispatched bags show >3% return across the month (defective / wrong order), 5% of that rep's incentive is held. Released next month if return rate normalizes. This prevents reps from pushing bags recklessly for volume without checking order accuracy.

**Step 5: Painter Growth Token Accounting**
₹50 cash token inside every 25kg Rustic bag is tracked as a **cost of goods sold line item**, not a payroll deduction. Swatch accounts for it separately in the product margin sheet (₹450 factory base → ₹635 landed cost includes this ₹50 token). HR ledger does NOT touch this — keeping payroll clean and product cost transparent.

**Step 6: Month-End Cut-Off Protocol**
- Day 1: System locks prior month's dispatch data
- Day 2: Zone pods reconcile with factory dispatch register
- Day 3: Finance approves final payout
- Day 5: Salary credited via NEFT
- Day 7: Dispute resolution window closes
