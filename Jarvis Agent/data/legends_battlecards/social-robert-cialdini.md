## STEP 2 — The 1-Tap Painter Funnel (Brunson Architecture)

**The "Free Token + Proof Card" Offer:**

Every 25kg Rustic bag contains a **Painters Growth Token (₹50 cash)** + a **QR code card** reading:

> *"Yeh token aapka hai. QR scan karo — apna video banao, ₹50 cash receive karo + next order pe extra ₹20 per bag bonus milta hai."*

**Funnel Path (One Tap):**
```
Painter scans QR
→ Lands on WhatsApp Business click-to-chat link (1-tap)
→ Auto-reply: Name, City, Product used, Bags purchased
→ Receives: Testimonial script template (in local dialect)
→ Records & sends video back via WhatsApp
→ Automation approves → ₹50 token disbursed within 24 hrs
→ Tagged as "Active Proof Painter" → added to regional pool
```
