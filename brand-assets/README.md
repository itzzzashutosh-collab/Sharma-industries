## Brand Logo Rules

1. **Primary Logo**: Use `logos/swatch_paints_logo_primary.png` for all official use.
2. **Minimum Size**: Never use logo below 80px width.
3. **Clear Space**: Maintain padding equal to the height of the "S" icon on all sides.
4. **Approved Backgrounds**: White, Off-white, Dark Navy.
5. **NEVER**: Stretch, recolor, add drop-shadows, or place on busy backgrounds.
